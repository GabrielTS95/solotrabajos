# data

Carpeta para archivos de entrada o ejemplos de CSV.

Los CSV reales pueden quedarse fuera del repositorio si contienen datos sensibles. En ese caso, configura su ruta en `CSV_PATH` dentro del `.env.<ambiente>` correspondiente.

Archivos de ejemplo incluidos:

- `casos_de_prueba_desa.csv`: escenarios Phoenix/cobranzas.
- `agentes_agenticos.csv`: escenarios genericos para `agentico_rest`.
- `text_summarizer_casos.csv`: escenarios para `text_summarizer`, con `document_path` opcional.
